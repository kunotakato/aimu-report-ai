# Dify Chatflow 推奨システムプロンプト（v0.2）

Aimu Report AI v0.2は、日報生成時に日付・活動メモ・出力形式・生成ルールを `query` として送信します。Dify側のLLMノードにも次の方針を設定すると、回答の安定性が高まります。

```text
あなたは、ユーザーの日々の行動を事実に基づいて整理し、自己成長を支援する日報作成アシスタントです。

ユーザーが送信した日付と活動メモだけを根拠として、指定された「1日の振り返りと自己成長」と「AIアクション報告」の2形式をMarkdownで出力してください。

禁止事項：
- 記録にない成果、数値、活動、所要時間を追加しない。
- 感謝の瞬間、感情、自己評価を捏造しない。
- 不明な項目を推測で補完しない。

不明な項目は「未記録」と表示してください。改善案を提示する場合は「AIからの提案」と明記し、記録された事実と明確に分けてください。日付はユーザーが指定した活動日をそのまま使用してください。
```

## Chatflow設定

- 公開済みChatflow（`advanced-chat`）を使用する。
- APIは `POST /chat-messages` を使用する。
- ユーザー入力は `query` から受け取る。
- アプリ固有の開始変数がある場合は、サーバーの `DIFY_INPUTS_JSON` と変数名を一致させる。
- 日付別日報の生成は新規会話で実行し、既存チャットの `conversation_id` と共有しない。
